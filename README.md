# Dijkstra's Algorithm Pathfinding Visualization

An interactive web application that visualizes Dijkstra's Algorithm for finding the shortest path between locations on a map. Built with HTML, CSS, JavaScript, and Leaflet.js.

## Features

- 🗺️ Interactive map interface using Leaflet.js
- 📍 Location markers for start and end points
- 🎯 Real-time visualization of Dijkstra's Algorithm
- 📊 Detailed path summary and statistics
- 🌙 Modern dark mode UI
- 📱 Responsive design
- 🎨 Smooth animations and transitions

## Core Functionality

- **Interactive Map**: Select locations on the map to set start and end points
- **Algorithm Visualization**: Watch the algorithm explore nodes and find the optimal path
- **Path Summary**: View detailed information about the chosen path
- **Distance Calculation**: See the total distance of the shortest path
- **Reset Functionality**: Clear the current path and start over

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Leaflet.js for map visualization
- Font Awesome for icons

## Setup Instructions

1. Clone the repository:
```bash
git clone [repository-url]
```

2. Open the project directory:
```bash
cd [project-directory]
```

3. Open `index.html` in your web browser

## Usage

1. Select a start location from the dropdown menu
2. Select an end location from the dropdown menu
3. Click "Find Path" to visualize the shortest path
4. View the path summary and statistics
5. Use the reset button to clear the current path

## UI Components

- **Location Selection**: Dropdown menus for start and end points
- **Control Panel**: Contains all interactive elements and information
- **Map View**: Interactive map showing the path visualization
- **Path Summary**: Displays algorithm statistics and path details
- **Legend**: Explains the different markers and colors used

## Color Scheme

- Start Node: Blue
- Visited Nodes: Yellow
- Path Nodes: Red
- Background: Dark theme (#1a1a1a)
- Accent Color: Green (#4CAF50)
